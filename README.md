# data-carpentry-python-ecology
Example of Data Carpentry Python for Ecologists implementation

## Overview

This is a workspace for Maine-Bridge participants to work through the Data Carpentry curriculum.

The curriculum page can be found here:
https://datacarpentry.github.io/python-ecology-lesson/

### Changes

The primary change is that we use Pixi instead of Anaconda. 

The [Portal Project](https://figshare.com/articles/dataset/Portal_Project_Teaching_Database/1314459) data is also already unzipped and included in the `data/` directory.
